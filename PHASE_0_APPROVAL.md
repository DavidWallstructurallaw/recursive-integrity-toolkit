## Approved decision effects

- Dual theory and product authority is adopted.
- The primary v0.1 domain is ML data and provenance pipelines.
- The canonical hero run reaches maximum observability Level 4 with a separate capability matrix.
- `generation` and `lineage_depth` remain separate.
- Composite parent references use `dataset_version::record_id`.
- External grounding remains distinct from source type and human review.
- Direct and lineage closure exposure use explicit lower and upper bounds.
- Support, diversity, tail, and extinction remain representation-bound.
- One-step extinction probability remains a simulation result.
- Ancestry HHI remains a topological toolkit operationalization.
- Phase 6 is split into required longitudinal analysis and optional experimental scenarios.
- Markdown is required, HTML remains optional.
- Near-duplicate analysis remains optional.
- Amplification-dominant analysis and universal scores remain deferred or forbidden.
- Code uses Apache-2.0, with reusable specifications and repository-created examples under CC BY 4.0, subject to final license-file creation.
- Theory PDFs retain their stated licenses and remain reference assets.
